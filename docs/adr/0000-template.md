# ADR-NNN: Short title of the decision

## Status

Proposed | Accepted | Deprecated | Superseded by ADR-NNN. Add the date of each change of status.

## Context

Date of the decision. The problem, the needs and the constraints that force a choice. Facts only, no solution yet.

## Options considered

1. **Option A.** One or two lines: what it is, what is good, what is bad.
2. **Option B.** Same.
3. **Option C (chosen).**

Keep the rejected options: they are the reason this file exists.

## Decision

The option chosen and why, in a few lines. Name what in the code or the contracts makes it real.

## Consequences

- Good: what the decision brings.
- Bad: what it costs, and the limits it accepts.
- Risks: what could go wrong, with a pointer to the risk matrix when there is an entry.

---

Rules: one decision per ADR, short (one page). Write it when the decision is taken. Never rewrite an accepted
decision: change its status and write a new ADR that supersedes it, or add a dated "Update" section.
